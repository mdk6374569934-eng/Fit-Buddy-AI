# FitBuddy Frontend

This directory contains the user interface templates and static assets for the FitBuddy AI application:

- `templates/index.html`: Responsive input form for personal details, goal selection, and intensity.
- `templates/result.html`: Personalized 7-day routine, nutrition tip card, and feedback submission section.
- `templates/all_users.html`: Admin panel with comparative view of original vs updated plans.
- `static/css/style.css`: Clean, modern gym-themed glassmorphism stylesheet.
- `static/images/gym-bg.jpg`: Cinematic fitness background image.
